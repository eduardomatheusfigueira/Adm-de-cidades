# Modelos para a turma

Coloque aqui arquivos `.json` salvos com **Dados → Perfil → 🎓 Salvar como modelo para a turma**.

Depois do deploy, um arquivo `public/modelos/aula-3.json` é aberto pelo link:

    https://SEU-SITE/?modelo=aula-3

O aluno vê o título e as instruções do modelo e escolhe "Abrir modelo"; o mapa, os dados,
a simbologia e as páginas do Estúdio são carregados, e o trabalho dele passa a ser salvo
automaticamente no próprio aparelho.

Use nomes sem espaços e sem acentos (letras, números, `-` e `_`).
